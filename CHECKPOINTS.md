# Checkpoints

No trained model weights are released in this repository yet.

Planned: once the manuscript is accepted (or otherwise cleared for release),
a checkpoint trained on the 160×160×32 benchmark configuration will be
published separately (e.g. Zenodo / Hugging Face Hub) and linked here, along
with the exact `run_reswfm.sh` invocation and commit hash used to train it.

Until then, `inference/` documents the expected input format and command so
you can run inference once you (a) have your own trained checkpoint, or
(b) the released checkpoint link above is added.
